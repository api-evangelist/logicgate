LogicGate is the maker of Risk Cloud, a no-code governance, risk, and compliance (GRC) platform that lets teams design, automate, and connect their risk and compliance programs. The Risk Cloud API v2 is an API-first, RESTful interface for managing the building blocks of a Risk Cloud environment - Applications, Workflows, Workflow Maps, Steps, Paths (edge/next/redirect), Fields, Records, and Access Audits - so organizations can integrate, automate, and build custom workflows against their risk data. Authentication is an HTTP bearer "API Token" minted via HTTP basic against the token endpoint, and API access requires the paid API Access add-on. The v2 OpenAPI 3.1 specification is published on GitHub as the single source of truth, alongside a Postman collection and interactive documentation.

**Areas:** Company · GRC · Governance Risk and Compliance · Risk Management · Compliance · Workflow Automation · Audit · No-Code

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for LogicGate: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
