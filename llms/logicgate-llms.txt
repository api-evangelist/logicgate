# LogicGate Risk Cloud API

> LogicGate Risk Cloud is a no-code GRC (governance, risk, and compliance) platform. The Risk Cloud API v2 is an API-first, RESTful interface for managing the building blocks of a Risk Cloud environment — Applications, Workflows, Workflow Maps, Steps, Paths (edge/next/redirect), Fields, Records, and Access Audits — so teams can automate and integrate their risk and compliance programs. Authentication is an HTTP bearer "API Token" (minted via HTTP basic against the token endpoint); API access requires the paid API Access add-on.

## APIs
- [Risk Cloud API v2 (OpenAPI 3.1)](https://github.com/LogicGateTech/openapi): API-first RESTful endpoints for Applications, Workflows, Steps, Paths, Fields, and Records
- [Risk Cloud API v2 docs](https://docs.logicgate.com/v2/index.html): interactive reference for the v2 endpoints
- [Risk Cloud API v1 docs](https://docs.logicgate.com/v1/index.html): legacy endpoints (records, fields, users, exports)
